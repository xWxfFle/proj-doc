## Фрагмент: Создание проекта

Создайте проект, чтобы хранить документы и управлять доступом участников.

## Предусловия

- Вы участник организации с ролью **Администратор** или **Редактор**.
- Организация уже создана.

## Шаги

1. Откройте раздел **Проекты**.
2. Нажмите **Создать проект**.
3. Введите название проекта (до 80 символов).
4. Нажмите **Сохранить**.

После сохранения открывается страница проекта. В боковой панели появляется новый пункт с указанным названием.

## Если что-то пошло не так

| Сообщение | Что сделать |
| --- | --- |
| Недостаточно прав | Попросите администратора выдать роль Редактор |
| Название уже занято | Выберите другое имя в пределах организации |

---

**Почему это соответствует стайлгайду:** тип документа — инструкция, предусловия, императив, UI в жирном, таблица ошибок вместо длинного текста.
