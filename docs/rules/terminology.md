# Терминология

## Словарь продукта (фрагмент)

| Термин | Значение | Не писать |
| --- | --- | --- |
| Организация | Юридическое или командное пространство в продукте | Компания, тенант (в пользовательских текстах) |
| Проект | Рабочая единица внутри организации | Репозиторий (если речь не о Git) |
| Участник | Пользователь с ролью в организации | Юзер, аккаунт |
| API-ключ | Секрет для программных запросов | Токен (если это именно key) |
| Вебхук | HTTP-уведомление о событии | Callback (в пользовательской доке) |

## Правила именования

- UI-элементы пишите как на экране: кнопка **Создать проект**.
- Имена API-полей — как в схеме: `project_id`, в backticks.
- Не смешивайте «логин» и «войти»: для действия — **Войти**, для поля — **Электронная почта**.

## Согласование новых терминов

1. Проверьте, нет ли термина в словаре.
2. Предложите термин в PR с обоснованием.
3. После merge обновите эту страницу.
