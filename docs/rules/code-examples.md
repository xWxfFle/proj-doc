# Примеры кода

## Общие требования

- Каждый пример должен быть **минимально полным**: его можно скопировать и запустить (или явно пометить как псевдокод).
- Указывайте язык в fence: `bash`, `json`, `python`, `http`.
- Секреты только как плейсхолдеры: `YOUR_API_KEY`, никогда реальные значения.

## Хорошо

```bash
curl -X GET "https://api.example.com/v1/projects" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Плохо

```bash
curl https://api.example.com/v1/projects -H "Authorization: Bearer sk_live_abc123"
```

## Пояснения к коду

- Перед блоком — одно предложение, что делает пример.
- После блока — что должно получиться (статус, фрагмент ответа).
- Длинные ответы сокращайте с комментарием `# ...`.

## Версии

Если пример зависит от версии API, укажите версию рядом с заголовком раздела: «Пример для API v1».
