# Примеры кода

## Общие требования

- Каждый пример должен быть **минимально полным**: его можно скопировать и запустить. Иначе явно пометьте блок как псевдокод.
- Указывайте язык в fence: `bash`, `json`, `python`, `http`.
- Секреты указывайте только как плейсхолдеры: `YOUR_API_KEY`. Реальные значения не публикуйте.

## Хорошо

Перед блоком кратко опишите задачу. Здесь пример получает список проектов:

```bash
curl -X GET "https://api.example.com/v1/projects" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Ожидаемый результат — ответ `200` и JSON со списком проектов:

```json
{
  "items": [
    { "id": "prj_01", "name": "Документация" }
  ]
}
```

## Плохо

В примере ниже нет пояснения, язык указан неявно, а в заголовке лежит настоящий секрет:

```bash
curl https://api.example.com/v1/projects -H "Authorization: Bearer sk_live_abc123"
```

## Пояснения к коду

- Перед блоком напишите одно предложение о том, что делает пример.
- После блока опишите ожидаемый результат: статус, фрагмент ответа или появление записи в UI.
- Длинные ответы сокращайте комментарием `# ...` или `"..."`.

Пример сокращения:

```json
{
  "id": "prj_01",
  "name": "Документация",
  "...": "остальные поля опущены"
}
```

## Версии

Если пример зависит от версии API, укажите версию рядом с заголовком раздела: «Пример для API v1».

Пример заголовка: `### Создание проекта в API v1`.
