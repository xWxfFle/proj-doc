## Заголовки

- Формулируйте заголовки как тему или действие: «Создание API-ключа», а не «Работа с ключами (общее)».
- Не ставьте точку в конце заголовка.
- Не нумеруйте заголовки вручную. Нумерацию при необходимости даёт оглавление или навигация.
- Соблюдайте иерархию: после H2 идёт только H3, без прыжков к H4.

Примеры:

| Избегать | Предпочитать |
| --- | --- |
| Общие сведения | Что такое организация |
| Работа с пользователями | Приглашение участника |
| 1. Настройка | Создание вебхука |

## Списки

- Нумерованный список используйте только для **упорядоченных шагов**.
- Маркированный список используйте для перечислений без порядка.
- Каждый пункт начинайте с заглавной буквы. Точку в конце ставьте, если пункт — полное предложение.
- Не смешивайте в одном списке глаголы-инструкции и существительные-сущности.

Пример нумерованного списка:

1. Откройте **Настройки → Разработчикам**.
2. Нажмите **Создать API-ключ**.
3. Скопируйте значение ключа и сохраните его в менеджере секретов.

Пример маркированного списка:

- Роль **Наблюдатель**
- Роль **Редактор**
- Роль **Администратор**

## Чек-листы

Для действий «проверить перед релизом» используйте task-list Markdown:

```markdown
- [ ] Собрана документация раздела «Проекты»
- [ ] Обновлён CHANGELOG
- [ ] В примерах нет реальных API-ключей
```
