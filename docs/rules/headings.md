# Заголовки и списки

## Заголовки

- Формулируйте заголовки как тему или действие: «Создание API-ключа», не «Работа с ключами (общее)».
- Не ставьте точку в конце заголовка.
- Не нумеруйте заголовки вручную — нумерацию даёт оглавление / навигация при необходимости.
- Соблюдайте иерархию: после H2 только H3, без прыжков.

## Списки

- Нумерованный список — только для **упорядоченных шагов**.
- Маркированный — для перечислений без порядка.
- Каждый пункт начинается с заглавной буквы; точка в конце — если пункт полное предложение.
- Не смешивайте в одном списке глаголы-инструкции и существительные-сущности.

## Чек-листы

Для действий «проверить перед релизом» используйте task-list Markdown:

```markdown
- [ ] Собрана документация
- [ ] Обновлён CHANGELOG
```
