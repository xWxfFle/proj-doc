# Форматирование

## Markdown

- Заголовки: `#` … `####` (глубже не уходите).
- Один H1 на файл.
- Между заголовком и текстом — пустая строка.
- Списки: `-` для маркированных, `1.` для нумерованных шагов.
- Код в строке: `` `имя_параметра` ``.
- Блоки кода — fenced с указанием языка:

````markdown
```bash
mkdocs serve
```
````

## Выделение

- **Жирный** — для UI-элементов и важных ограничений: нажмите **Сохранить**.
- *Курсив* — для введения термина при первом упоминании.
- Не используйте CAPS LOCK для акцента.

## Ссылки

- Текст ссылки осмысленный: [правила языка](language.md), не «тут» / «здесь».
- Внешние ссылки проверяйте на актуальность при ревью.

## Таблицы

Используйте таблицы для сравнения вариантов, параметров API и «избегать / предпочитать».
Не используйте таблицы для длинных абзацев.

## Admonitions (MkDocs)

Для предупреждений:

```markdown
!!! warning "Важно"
    Без API-ключа запрос вернёт `401`.
```

Типы: `note`, `tip`, `warning`, `danger`.
