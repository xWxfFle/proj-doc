# Структура документов

## Выбор типа документа

| Тип | Вопрос читателя | Структура |
| --- | --- | --- |
| Tutorial | «Как начать с нуля?» | Цель → предусловия → шаги → проверка результата |
| How-to | «Как сделать X?» | Цель → шаги → результат / ошибки |
| Reference | «Что означает параметр?» | Алфавит / группы полей, без сюжета |
| Explanation | «Почему так устроено?» | Контекст → концепция → связь с другими частями |

## Обязательные блоки в начале

Каждый документ (кроме коротких reference-страниц) начинается с:

1. **Заголовка H1** — что описывает страница
2. **Краткого введения** (1–3 предложения) — для кого и зачем
3. **Предусловий** (если нужны права, версии, доступы)

## Именование файлов

- Только латиница, нижний регистр, дефисы: `create-api-key.md`
- Имя файла отражает тему, не номер: не `doc1.md`
- Один файл — одна тема

## Длина страницы

- Целевая длина: до экрана 3–5 минут чтения
- Если больше — разбейте на подразделы или отдельные страницы и свяжите перекрёстными ссылками

## Навигация MkDocs

Новый раздел добавляйте в `mkdocs.yml` → `nav` в том же PR, что и контент.
