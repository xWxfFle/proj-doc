# Структура документов

## Выбор типа документа

Типы документов называйте по-русски. В скобках указан привычный английский термин из Diátaxis.

| Тип документа | Вопрос читателя | Пример темы |
| --- | --- | --- |
| Обучение (tutorial) | «Как начать с нуля?» | «Первый проект за 10 минут» |
| Инструкция (how-to) | «Как сделать X?» | «Как создать API-ключ» |
| Справка (reference) | «Что означает параметр?» | «Параметры метода `POST /projects`» |
| Пояснение (explanation) | «Почему так устроено?» | «Чем организация отличается от проекта» |

Структура по типам:

| Тип документа | Структура |
| --- | --- |
| Обучение | Цель → предусловия → шаги → проверка результата |
| Инструкция | Цель → шаги → результат / ошибки |
| Справка | Алфавит или группы полей, без сюжета |
| Пояснение | Контекст → концепция → связь с другими частями |

## Обязательные блоки в начале

Каждый документ, кроме коротких справочных страниц, начинается с:

1. **Заголовка H1** — что описывает страница.
2. **Краткого введения** (1–3 предложения) — для кого и зачем.
3. **Предусловий** — если нужны права, версии или доступы.

Пример начала инструкции:

```markdown
# Создание API-ключа

Создайте API-ключ, чтобы вызывать API продукта из своего сервиса.

## Предусловия

- Роль **Администратор** в организации.
- Доступ к разделу **Настройки → Разработчикам**.
```

## Именование файлов

- Используйте только латиницу, нижний регистр и дефисы: `create-api-key.md`.
- Имя файла отражает тему, а не номер: не `doc1.md`.
- Один файл — одна тема.

Примеры хороших имён: `invite-member.md`, `webhook-events.md`, `projects-api.md`.

## Длина страницы

- Целевая длина — 3–5 минут чтения.
- Если текст длиннее, разбейте его на подразделы или отдельные страницы и свяжите перекрёстными ссылками.

Пример: страницу «Участники» лучше разделить на «Приглашение участника», «Роли и права» и «Удаление участника».

## Навигация MkDocs

Новый раздел добавляйте в меню навигации `mkdocs.yml` → `nav` в том же PR, что и контент.

Без пункта в `nav` страница не появится в боковом меню сайта.

Пример фрагмента меню:

```yaml
- Правила:
    - Создание API-ключа: rules/create-api-key.md
```
